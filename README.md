# ShowShow

Suivre les séries, docus et films Apple TV : ce qui est vu, en cours ou à voir.

- **Catalogue commun**, mis à jour chaque semaine, lu en lecture seule depuis un Google Sheet.
- **Connexion avec un compte Google** : ShowShow crée un seul fichier, « ShowShow – Ma sélection », dans le Google Drive de chaque personne, et n'a accès à rien d'autre (autorisation `drive.file`).
- Affiches : [TMDB](https://www.themoviedb.org/). Ce produit utilise l'API TMDB sans être approuvé ni certifié par TMDB.

Site statique (HTML, CSS, JavaScript), hébergé sur GitHub Pages. Les réglages sont dans `config.js`.
